# Contributor Code of Conduct

This project adheres to No Code of Conduct.  We are all adults.  We accept anyone's contributions. Nothing else matters.

For more information please visit the [No Code of Conduct](https://github.com/domgetter/NCoC) homepage.

# Artificial Intelligence policy

AI assistance is welcome in project contributions, including code, documentation, commit messages, and pull request summaries. If you use AI, briefly disclose how you used it in your submission and state what it helped with.
